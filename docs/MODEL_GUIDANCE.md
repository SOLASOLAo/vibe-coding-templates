## GPT-6 Astra 的相关指导

OpenAI 建议重新审视旧技能和提示词中的繁复流程：资料按需加载，说明用户允许的行动范围，并给出任务的完成条件。模型可能对限制更敏感，也可能执行超出小改动所需的检查；遇到这些现象时应澄清具体边界和验证范围。

依据：[Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)（2026-09-11），以及 [GPT-6 Astra 指南](https://developers.openai.com/api/docs/guides/latest-model)。官方页面会更新，采用新的模型或 API 参数前重新核查对应说明。

## 在本模板中的应用

- AGENTS 保留具体约束及入口，进度由 HANDOVER / TODO 维护，设计与证据放 docs。
- 不把所有任务绑定成固定会话流程，也不把完成第一版代码等同于验收完成。
- 本模板没有打包 skills。只有出现明确、可复用的专门流程时再添加，描述简短且触发条件具体，详细资料按需展开。
- 不同模型可能需要不同引导。需要代理协作时，按使用环境明确分工、输出和写文件边界；不把多代理作为所有任务的默认要求。

这些是对官方建议的模板应用，未宣称已验证所有模型的执行行为。API、工具并发和代理运行时属于使用环境，本模板只提供项目协作约定。
